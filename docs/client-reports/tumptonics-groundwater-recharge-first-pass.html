Limitations

This first pass is based on public mapping and local terrain analysis. It is suitable for scoping, discussion and planning field observations. It is not a substitute for a hydrogeological assessment, groundwater monitoring, abstraction data review, or tracer testing.

The recharge investigation area on the map is a topographic hypothesis only. It should be checked against bedrock geology, superficial deposits, aquifer designation, groundwater vulnerability mapping and field evidence before being described as a spring catchment.
